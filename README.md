# Ethara Task Manager

A full-stack team task management web application for project collaboration, task assignment, role-based access, progress tracking, and productivity dashboards.

## 🚀 Live Demo
🔗 https://ethara-task-manager-lake.vercel.app

Whenever you sign up, please use the following format:

Email: sampleuser@ethara.ai 
Password: sampleuser

This means the password will always be the same as the text before **@ethara.ai** in the email address.

eg. email: sampleadmin@ethara.ai
    password: sampleadmin

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone <your-github-repo-link>
cd TeamTracker-main
```

### Install Dependencies

Backend:

```bash
npm install
```

Frontend:

```bash
cd client
npm install
```

### Run Application

Backend:

```bash
node server.js
```

Frontend:

```bash
cd client
npm run dev
```
